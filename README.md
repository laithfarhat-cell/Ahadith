# قاعدة بيانات الأحاديث الشريفة (Ahadith)

مشروع يحتوي على سكريبتات بايثون لتحميل كتب السنة النبوية التسعة وبناء قاعدة بيانات SQLite محلية للبحث السريع.

## الكتب المشمولة (الكتب التسعة)
- صحيح البخاري (`bukhari`)
- صحيح مسلم (`muslim`)
- سنن أبي داود (`abudawud`)
- جامع الترمذي (`tirmidhi`)
- سنن النسائي (`nasai`)
- سنن ابن ماجه (`ibnmajah`)
- موطأ مالك (`malik`)
- مسند الإمام أحمد (`ahmed`)
- سنن الدارمي (`darimi`)

## المتطلبات
- Python 3.10+ (لا يحتاج إلى مكتبات خارجية، يعتمد على المكتبة القياسية فقط).

## طريقة الاستخدام

### 1. تحميل الأحاديث وبناء قاعدة البيانات
لتحميل **جميع الكتب التسعة** وبناء قاعدة البيانات `data/ahadith.db`:
```bash
python3 fetch_ahadith.py
```

أو لتحميل كتاب محدد فقط (مثلاً صحيح البخاري):
```bash
python3 fetch_ahadith.py --book bukhari
```

### 2. البحث في الأحاديث
```bash
python3 search_ahadith.py "prayer" --limit 5
```
أو التصفية حسب كتاب معين:
```bash
python3 search_ahadith.py "intentions" --book bukhari --limit 3
```
